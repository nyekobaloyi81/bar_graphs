This a beginner data visualization project

Brief:
Settle the G.O.A.T.(Greatest of all time) debate, statistically, who is the better football player: Messi or Ronaldo? 

Process:
1. Getting data from Kaggle
2. Create a bar graph of all the goals Messi has scored over his career
3. Create a bar graph of all the goals Ronaldo has scored over his career 
4. Compare the data
